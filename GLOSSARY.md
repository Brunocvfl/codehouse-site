# Code House (site)

Site institucional da Code House: apresenta os serviços e leva o visitante a uma conversa no WhatsApp.

## Contato

**Contato WhatsApp**:
O canal pelo qual o visitante fala com a Code House; todo botão de orçamento termina nele.
_Avoid_: link do zap, botão de contato

**Saudação**:
A abertura fixa de toda mensagem enviada pelo site, igual em todos os pontos de entrada.
_Avoid_: mensagem padrão, prefixo

**Assunto**:
O que o visitante quer tratar, escrito depois da Saudação; vem do serviço escolhido, da ideia digitada ou do padrão.
_Avoid_: msg, texto

## Serviços

**Serviço**:
Um formato de entrega que a Code House oferece, como site institucional ou landing page.
_Avoid_: produto, plano, formato

**Catálogo de Serviços**:
A lista dos Serviços oferecidos; todo Projeto pertence a um deles.
_Avoid_: menu de serviços, tipos

## Portfólio

**Projeto**:
Um trabalho entregue a um cliente, publicado como estudo de caso com página própria.
_Avoid_: case, trabalho, item

**Capa**:
A imagem principal do Projeto: aparece no topo do estudo de caso, no card do portfólio e no Carrossel de Projetos.
_Avoid_: thumbnail, banner, cover

**Rascunho**:
Projeto ainda não publicado; não aparece em nenhuma página do site.
_Avoid_: oculto, privado

**Carrossel de Projetos**:
A seção Projetos da página inicial, que mostra todos os Projetos publicados, na ordem do portfólio.
_Avoid_: slider, destaques

**Rótulo**:
A linha que situa o Projeto: o tipo de entrega e para qual cliente. No topo do estudo de caso, vem com o ano.
_Avoid_: subtítulo, categoria
